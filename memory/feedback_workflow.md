커밋/푸시/배포는 사용자가 명시적으로 요청할 때만 실행하고, 실행 전 반드시 먼저 물어본다.

**Why:** 사용자가 직접 타이밍을 컨트롤하길 원함. 한꺼번에 묶어서 진행하는 경우가 있음.
**How to apply:** 코드 수정 후 자동으로 커밋/푸시하지 말 것. 커밋/푸시할 준비가 됐는지 먼저 물어보고, "응" 또는 명시적 승인 후에만 실행.

---

메모리는 항상 프로젝트 레포 내 `memory/` 폴더의 md 파일에 저장한다.

**Why:** 다른 환경(다른 PC 등)에서도 git을 통해 메모리에 접근할 수 있어야 함. Claude 시스템 폴더(`C:\Users\...\.claude\`)는 로컬에만 존재함.
**How to apply:** 메모리 업데이트 시 `D:\Dropbox\0_잡부\개발\portfolio2026\memory\` 경로에도 반드시 저장할 것. 세션 종료 전 변경사항을 커밋/푸시 요청 시 memory 파일도 함께 포함.
